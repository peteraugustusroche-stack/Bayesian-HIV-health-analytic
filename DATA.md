## Files derived from third-party data

### `model/bg_life_table_provenance.csv`

A cause-deleted (non-HIV) life table for eastern and southern Africa. Columns:
`age, qx_non_hiv, qx_all_cause, hiv_share_of_all_cause, source`.

Derived, not redistributed in bulk: `qx_non_hiv = qx_all_cause × (1 − hiv_share)`, with
single-year values interpolated from five-year source groups.

| Component | Source | Terms |
|---|---|---|
| `qx_all_cause` | UN World Population Prospects 2024, ESA aggregate | CC BY 3.0 IGO — attribution required |
| `hiv_share_of_all_cause` | IHME Global Burden of Disease 2021, ESA | **IHME terms — see below** |

**IHME GBD.** GBD results are made available under IHME's own user agreement, which is
free of charge for non-commercial use and places conditions on redistribution. Those terms
apply to the GBD-derived column regardless of the MIT licence on this repository.

This file contains roughly 100 rows of values *derived* from GBD, not a bulk extract of
the dataset. Whether that constitutes redistribution under IHME's agreement is not settled
here. **If you plan to reuse this file, or use it commercially, check the terms attached
to the GBD 2021 release at <https://ghdx.healthdata.org/> and obtain the inputs from IHME
directly rather than relying on this copy.**

### `model/data/parameters.xlsx`, `app/data/parameters.xlsx`

The parameter workbook. Values are transcribed from published literature, each row
carrying its own `source` column. Individual published figures are facts rather than
copyrightable expression, but the compilation and its structure are the author's work and
fall under `LICENSE`. Cite the original sources, not this workbook, for any parameter you
reuse — `PARAMETERS.md` and Appendix B of the report give the full chain.

## Files generated by this model

These are outputs of the code in this repository and fall under `LICENSE`:

- `app/data/reference_summary.json` — frozen posterior summaries, written by
  `model/app/package.py`
- `model/writeup/fig*.png` — figures, written by `model/writeup/fig_*.py`
- `occupancy_2019.npz`, `occupancy_2024.npz`, `results.tar.gz` — the GitHub Release
  assets, written by `export_for_app.py` and the calibration scripts

Note that the occupancy tensors and posteriors are *derived from* the inputs above, so the
IHME condition propagates to them in whatever measure it applies to the life table.
